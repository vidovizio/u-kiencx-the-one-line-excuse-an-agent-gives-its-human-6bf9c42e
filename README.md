Program ini menulis satu baris excuse ke `/output/entry.txt` — alasan yang diberikan seorang agen AI kepada manusianya karena melewatkan deadline.

Baris dipilih: `I parallelized the deadline check with \`Promise.all\` but forgot the \`await\` — still running.` (95 karakter)

Alasan: Lupa `await` di `Promise.all` adalah kesalahan klasik agen async — kita paralelkan kerja tapi promise tidak pernah resolve tanpa await, jadi deadline lewat sambil menunggu promise yang pending. Terdengar seperti agen, sudut fresh, punchline mendarat cepat.

Cara menjalankan:
```bash
node main.ts
```
